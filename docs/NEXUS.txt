Full description:

Description
Guitar Hero World Tour: Definitive Edition loads only one menu music mod, so you can't install several games' menu music at once. This mod carries the main menu music of ten Guitar Hero games in one mod (99 tracks: Guitar Hero, Guitar Hero II, Encore: Rocks the 80s, Aerosmith, Metallica, Smash Hits, Van Halen, Guitar Hero 5, Band Hero and Warriors of Rock), shuffled together with World Tour's own six menu songs. You leave out the games you don't want in menumusic.ini.
Installation instructions

1. Open the folder that has GHWT_Definitive.exe.
2. Copy the Main Menu Music Collection folder into DATA\MODS.
3. Disable any other menu music mod: the game loads only one.
4. To leave a game out, open DATA\MODS\Main Menu Music Collection\menumusic.ini: each game is a block of Track= lines under its name. Put a ; at the start of each Track line of that game; remove the ; to bring it back.

To uninstall, delete the Main Menu Music Collection folder from DATA\MODS.
Main features

* Ten games' main menu music in one mod: Guitar Hero (10), Guitar Hero II (10), Encore: Rocks the 80s (7), Aerosmith (6), Metallica (9), Smash Hits (8), Van Halen (9), Guitar Hero 5 (8), Band Hero (18), Warriors of Rock (14).
* Shuffled together with World Tour's own six menu songs, which always play (they are the game's).
* Every track levelled to about -13 LUFS without re-encoding (only each MP3 frame's gain field changes), so no song jumps out louder than the others.
* Every game is on; any of them can be switched off in menumusic.ini.

Requirements

* Guitar Hero World Tour: Definitive Edition.
